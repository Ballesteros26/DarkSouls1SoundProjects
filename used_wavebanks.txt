This file contains a list of sound banks that are used in projects
that are not named the same as that sound bank. These sound banks must be
(manually) kept in sync. If one project makes changes to a shared sound
bank, then all projects that share that sound bank must make the exact
same changes.

However, in some limited cases, it should be possible to not update the 
shared projects, namely when rebuilding the bank to change a sample 
that is not referenced in the shared projects. Note that *removing*
such a sample is not possible, but modifying the wavetable and then 
rebuilding the bank should work correctly.

For this reason, it's highly recommended to not edit frpg_main unless
you *really* need to.

In a few cases (marked with an X), the .fev file references a sample
in the extra sound bank that the .fev file corresponding to that
sound bank does not. In these cases, cleaning "unused" samples from
the sound bank's corresponding project will remove this sample which
is actually used by the X-marked .fev file.

Format:

bank_name
    .fev referencing bank_name
        wavetable from bank_name referenced by this .fev

====
